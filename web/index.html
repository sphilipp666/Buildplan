Browser-Sicherheitshinweis (HTTPS / HTTP)

Diese Website läuft über verschlüsseltes https:// (GitHub Pages).
Dein Minecraft-Server stellt BlueMap unter http://161.97.151.79:8100 (ungesichertes HTTP) bereit.
Moderne Browser blockieren unverschlüsselte HTTP-iFrames innerhalb von HTTPS-Seiten (Mixed Content Security).

🗺️ BlueMap im neuen Tab öffnen
💡 Eingebettete Ansicht nutzen:
• Lokal: Starte den Planer auf deinem PC mit start-web.bat (unter http://localhost:8080). Da beide über HTTP laufen, ist die Livemap direkt im Split-Screen nahtlos eingebettet!
• Online: Richte für deinen Server ein SSL-Zertifikat (HTTPS) ein (z. B. via Nginx Proxy Manager, Caddy oder Cloudflare Tunnel).
📍 Transform-Gizmo aktiv (am Origin)
Steuerung:
• Linksklick + Ziehen: Drehen
• Rechtsklick + Ziehen: Schwenken (Pan)
• Mausrad: Zoomen
• Pfeile am Gizmo: Ganzzahlige Koordinaten verschieben
